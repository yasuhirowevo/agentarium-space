# README デモ更新スキルの憲法

## 目的

Agentarium Space の見た目と動きを、個人情報を含まない実アプリのデモとして伝え、アプリの更新後も README の紹介素材を更新できるようにする。

## 不変条件

- 撮影用の指示・セッション・プロジェクト情報はゼロから作った架空データを使う。普段のログや個人のプロファイルを公開用素材の入力にしない。
- 実際のアプリのパーサ・状態計算・UI を通して撮影し、架空データによるデモであることを読者に明示する。
- 公開前に、入力から表示データまで、画像、動画の全期間、メタデータを検査する。個人情報・機微情報・個人環境を識別する情報を含む素材は公開しない。
- 撮影・更新・公開はユーザーから依頼された範囲で行い、スキルの呼び出しだけを追加の公開・マージ権限と解釈しない。

## 非対象

- 通常利用のログやプロファイルの収集・加工・削除。
- 見栄えのための本体機能や計器の改変。
- 全アップデートでの自動再撮影、アプリのリリース運用。

## この文書の変更

CONSTITUTION.mdの変更・削除は、それを対象とするユーザーの明示指示の範囲でのみ行える。通常の修正・改善依頼はその許可を含まない。
