# Security Policy

## Supported Version

Only the latest revision of the default branch is supported.

## Reporting a Vulnerability

Use **Report a vulnerability** under the repository's **Security > Advisories**
page. Do not disclose a suspected vulnerability in a public comment or another
public channel.

Reports should include the affected revision, reproduction steps, expected
impact, and whether the issue can expose session data beyond the local machine.
This repository does not accept public issues or pull requests.
